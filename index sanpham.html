Cấu hình ban đầu

Dán URL Google Apps Script Web App của bạn vào đây để bắt đầu.

  1. Mở Google Sheet → Extensions → Apps Script
  2. Paste nội dung file google-apps-script.gs
  3. Deploy → New deployment → Web app → Anyone
  4. Copy URL và dán vào ô bên dưới
